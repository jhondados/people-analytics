# 👥 People Analytics Dashboard

> Painel completo de people analytics com IA. Consolida headcount, turnover, performance e engajamento com insights preditivos para o RH.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/people-analytics/

## 📊 Resultados-chave (KPIs)
**tempo real** Headcount · **preditivos** Insights · **48** KPIs · **data-driven** Decisão

## 🧠 Tecnologias de IA
ML · Analytics · Forecasting

## ✨ O que faz
- Headcount e turnover em tempo real
- Insights preditivos
- 48 KPIs de RH
- Benchmark de mercado

## 🗄️ Fonte de dados real
[RH consolidado](https://www.gov.br/trabalho)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com RH consolidado
2. **Processamento com IA** — ML · Analytics · Forecasting
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
